# Song of the Street Tree

A sound-art app by Kamala Sankaram that turns New York City street tree stumps into records. Each stump has two tracks: an **indexical** track (the stump's surface read by a virtual stylus spiralling inward at 33⅓ RPM) and a **metaphorical** track (ring count × 8 Hz, shaped by the grain). A crossfader moves between them.

This is a cross-platform mobile app (iOS and Android) built with [Capacitor](https://capacitorjs.com) around a plain HTML/CSS/JavaScript front end, bundled with [Vite](https://vitejs.dev).

## Status

Phase 1 of the migration plan: the original web prototype (`song_standalone.html`) running as a phone app.

- Archive page, Leaflet map, and stump cards, restyled for phone screens
- Two-track player on Web Audio, so the crossfader also works on iPhone (iOS ignores `<audio>.volume`)
- Lock-screen controls via the Media Session API; iOS background audio enabled in `Info.plist`
- Media and fonts bundled as files (the prototype embedded them as 43 MB of base64)

Next phases: a shared audio engine ported from `tree_stump_audio.py`, photo input (default), LiDAR `.obj` import (optional), and a shared online archive.

## Develop

Requires Node 20+.

```sh
npm install
npm run dev        # open http://localhost:5173 in a browser
```

## Run on a phone

```sh
npm run sync       # builds the web app and copies it into ios/ and android/
npx cap open ios       # opens Xcode (macOS only); pick a device and press Run
npx cap open android   # opens Android Studio; pick a device and press Run
```

## Sound engine

`src/engine/` is the stump-to-sound engine ported from Kamala's `reference/tree_stump_audio.py`: ring detection, the indexical track and the metaphorical track. It produces the same audio as the Python script (checked by `npm test`, which runs both on a synthetic stump and compares them sample by sample) and renders a full 22-minute side in well under a minute.

```sh
npm test                                               # compare against the Python (needs python3)
npm run render -- scan.obj "Littleleaf Linden" 32      # write both WAVs next to the scan
```

### Photo input

"Add a Stump" turns a photo of a cut face into a record on the phone (`src/engine/photo.js`, `src/photo-input.js`):

- The person marks the stump with two taps (centre, then edge). Brightness stands in for height, with the lighting removed.
- The photo is sampled at about 4,400 scattered points, the density of a Polycam scan, and the stylus jumps from nearest point to nearest point as it does on a mesh. Reading every pixel instead piles the sound into the 120–500 Hz mids; reading like a scan keeps the scan's space and low weight.
- The species is suggested from removed trees near the photo's GPS (or the phone's location) in NYC Parks' Forestry Tree Points, or left as Unknown.
- Both tracks are made live in an AudioWorklet (`src/engine/worklet.js`), so no audio files are stored. Stumps are kept in `localStorage` on the phone until the shared archive exists.

## Layout

| Path | What it is |
| --- | --- |
| `index.html` | Page markup |
| `src/main.js` | Cards, map, popups, add-a-stump form |
| `src/photo-input.js` | Photo decoding, EXIF location, tree-map species lookup, saved stumps |
| `src/player.js` | Two-track Web Audio player and crossfade |
| `src/stumps.js` | Stump records (replaced by the shared archive later) |
| `src/styles.css` | Styles, colours taken from the stump photograph |
| `src/engine/` | Sound engine: mesh and photo surfaces, ring detection, both tracks, live worklet, species table |
| `reference/` | The original desktop generator, kept as the reference for the engine |
| `test/` | Engine-vs-Python comparison and photo reader tests |
| `public/media/` | Linden recordings, scan video and hero photo |
| `ios/`, `android/` | Native projects generated by Capacitor |
